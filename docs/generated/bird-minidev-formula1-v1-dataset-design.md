# BIRD-derived Formula 1 acceptance dataset

This standalone bundle retains **all 66 Formula 1 tasks and all 493,257 original rows across 13 tables** from BIRD Mini-Dev. It is a reviewed corrected variant, not an official BIRD leaderboard score. It contains 28 simple, 26 moderate and 12 challenging tasks; 47 reference queries genuinely combine CSV and PostgreSQL tables. No cases are exempted because of current product limitations.

The official [Mini-Dev repository](https://github.com/bird-bench/mini_dev) points to the [canonical Hugging Face dataset](https://huggingface.co/datasets/birdsql/bird_mini_dev). Source annotations are pinned to revision `f65faf4ae3b638c1fa6df1d3370c8d92c8366301`; the official archive is `https://bird-bench.oss-cn-beijing.aliyuncs.com/minidev.zip`. The original extracted SQLite database SHA256 is `79770caf966707e35516fa566e24b40ae515c74ec1ec4631235245645b87b24d`. Attribution and all downloaded-file checksums are in `source/provenance.json`; CC BY-SA 4.0 legal text is included. Cite Li et al., *Can LLM Already Serve as a Database Interface? A BIg Bench for Large-Scale Database Grounded Text-to-SQLs*, NeurIPS 2023. This adaptation retains the same CC BY-SA 4.0 licence.

CSV dimensions are circuits, constructors, drivers, seasons and status. PostgreSQL facts are races, constructorResults, constructorStandings, driverStandings, lapTimes, pitStops, qualifying and results. Every original row is preserved, including unknown values and repeated facts. Identifier names are reversibly lowercased; SQLite INTEGER becomes Int64, REAL becomes Float64, DATE becomes Date32 and text remains Utf8. Declared nullability and primary-key contracts are retained. CSV nonnullable columns are explicitly enforced by the reader. Null tokens `\N` and empty strings remain distinct.

`compose.yaml` pins PostgreSQL 16.6, publishes a random loopback port and provides an isolated database volume. The one-shot bootstrap verifies all CSV checksums, transactionally recreates its schema, loads all eight fact tables and verifies counts. The harness owns unique Compose project names and teardown. The project binds `BIRD_DATABASE_URL`, explicitly disabling TLS only for the local fixture.

The canonical case questions are byte-identical to the PostgreSQL Mini-Dev edition. Both PostgreSQL and SQLite original questions, evidence and SQL are retained in `source/selected_original.json`, with the entire original annotation files also retained. Schema descriptions and official evidence are authored catalog input; reference SQL and expected rows are separate artifacts. Known evidence typos for nationality in task964 and birth-year bounds in988 are resolved using the corresponding official SQLite evidence. Original malformed evidence remains available in provenance.

`source/adjudications.json` records every adapted query and correction reason. Reviewed corrections address missing requested projections, mistaken row/entity grain, missing-value ordering, finish position versus fastest-lap rank, chronology, and incomplete timing parsing. Task906 preserves the original reference cumulative championship points measure as a reviewed resolution of ambiguous points wording; official evidence does not specify that measure. Task978 counts distinct geographic venues `(location,lat,lng)`, as a reviewed resolution preserving the original SQL's DISTINCT grain; official evidence specifies location/coordinates and country but not the count grain: historical A1-Ring and Red Bull Ring entries occupy the same coordinates. Task1014 returns the minimum observed nonnull lap record per Italian circuit, with circuit identity/name; historical circuits without an observed record have no record to list. Ranked populations use documented stable identity tie breaks. No natural-language task is shortened to accommodate its original erroneous SQL.

The request clock is fixed at `2026-10-04T00:00:00Z`, UTC. Current-timestamp SQL is explicitly substituted, and SQLite's host-clock functions receive the same context. Age retains the officially evidenced year-difference definition. Three variable-scale PostgreSQL measurement numerics are explicitly cast to Float64 for a portable result contract; age is Int64. The dataset contains no monetary measurements. Floating comparison tolerance is absolute `1e-7`, relative `1e-9`; identifiers, strings, dates and integer counts remain exact. The two multiple-row ranking tasks988/1011 require ordered results.

Independent reference generation uses original SQLite and an isolated native PostgreSQL container loaded with all13 original tables. This all-PostgreSQL oracle is independent of the tested mixed-source project. Corrected reference queries execute successfully for all66 cases and agree as multisets; ranked tasks also retain reference ordering. Every original lapTimes duration (400,524 records) passes component-range validation and Decimal parsing agrees exactly with its original millisecond field. Details are in `source/duration-audit.json`, `source/corrected-reference-executions.json` and `source/oracle-review.json`. Golds never come from Semantic DB output.

Reproduce with `uv run --with sqlglot --with 'psycopg[binary]' python tests/datasets/bird-minidev-formula1-v1/bootstrap/reference_oracle.py --report source/corrected-reference-executions.json`, then `python3 tests/datasets/bird-minidev-formula1-v1/bootstrap/gold_from_references.py`. The author generator requires SQLGlot and reconstructs provider exports/catalog/cases from immutable sources. Docker commands use the session's `sg docker` wrapper. Runtime SQL and Luna Ask acceptance are performed by the parent orchestrator; reference agreement is not a claim of product success.
